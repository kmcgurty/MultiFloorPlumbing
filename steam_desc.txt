Plumb any number of rain barrels together, giving you water access in a basement.

[h2]What?[/h2]
This mod slightly changes the logic around plumbing, making it so you can chain rain barrels together. This means a sink on any floor can have access to water.

[h2]Why?[/h2]
My kitchen is in a basement, and I was disappointed I couldn't get water to my sink. The other mods (LG Plumbing) are either: AI generated, or too OP.

[h2]Instructions[/h2]
I'll try to get screenshots at some point. For now:

1. Place a rain barrel on your roof
2. Place a rain barrel directly below it (same tile X, Y)
3. Repeat #2 as many times as you wish
4. Place a sink directly below the last barrel
5. Plumb them all together.

The plumbing order doesn't matter, but top -> down will be the most reliable.

If you need to reset the "plumbed" status of an object, pick it up and place it down. After placing it, you'll have the option to plumb it again.

[h2]Limitations[/h2]
Unfortunately, the 3x3 check does not work past 1 floor level. The barrel coordinates (X, Y) need to match for it to recognize them as a water source. This is a hard limitation that can't be bypassed in a Lua mod.

[h2]How does it work?[/h2]
Plumbing in Project Zomboid is extremely complex. Notably, every time you request water from something, it checks if its external water source is plumbed to something else. If it is, it rejects it as a valid source. This mod (basically) bypasses those checks, letting you plumb any number of rain barrels together.

The actual details are more complex than that, so I urge you to read the source code. You can find it here: https://github.com/kmcgurty/MultiFloorPlumbing

[h2]Compatibility[/h2]
Works in singleplayer and multiplayer b42. Tested on build 42.21.0.

If any of the code around plumbing changes, this mod will very likely break. It's extremely specific to the game's current logic, and takes advantage of a couple Java functions. It is probably unwise to combine multiple plumbing mods.
